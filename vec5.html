ক. অবস্থান ও স্বাধীনতা ভিত্তিক ভেক্টর A. Position & Freedom Based Vectors

ভেক্টরের পাদবিন্দু কোথায় — সেটা কি ইচ্ছেমতো বসানো যায়? Where is the tail of the vector — can it be placed anywhere?

১
স্বাধীন ভেক্টর Free Vector
Free Vector
▼
🔖 সংজ্ঞা 🔖 Definition

কোনো ভেক্টর রাশির পাদবিন্দু (tail) কোথায় হবে তা যদি ইচ্ছেমতো পছন্দ করা যায়, তবে সেই ভেক্টরকে স্বাধীন ভেক্টর বলে। If the tail point of a vector can be chosen freely (placed anywhere), then that vector is called a Free Vector.

💡 উদাহরণ 💡 Example

5 N মানের পূর্বমুখী বল — এটা যেকোনো জায়গা থেকে আঁকলেও একই ভেক্টর বোঝায়। পাদবিন্দু যেখানেই হোক, মান ও দিক একই থাকলেই হলো। A 5 N eastward force — no matter where you draw it from, it represents the same vector. As long as the magnitude and direction are the same, the tail can be anywhere.

🧠 মনে রাখো 🧠 Remember

স্বাধীন = মুক্ত = পাদবিন্দু যেকোনো জায়গায় বসাতে পারো। ভেক্টরকে শুধু "সরিয়ে" (translate) নিয়ে গেলে একই ভেক্টর থাকে। Free = the tail can be placed anywhere. If you "translate" (slide) the vector, it remains the same vector.

▲ দুটি ভেক্টর একই মান ও দিক — পাদবিন্দু ভিন্ন — তবুও সমান (স্বাধীন ভেক্টর) ▲ Two vectors same magnitude & direction — different tails — still equal (Free Vectors)
২
সীমাবদ্ধ ভেক্টর Localized Vector
Localized Vector
▼
🔖 সংজ্ঞা 🔖 Definition

কোনো ভেক্টরের পাদবিন্দু যদি ইচ্ছেমতো পছন্দ করতে দেওয়া না হয় অর্থাৎ একটি নির্দিষ্ট বিন্দুকে পাদবিন্দু হিসেবে ঠিক করে রাখা হয়, তাহলে সেই ভেক্টরকে সীমাবদ্ধ ভেক্টর বলে। If the tail of a vector cannot be placed freely — it must start from a specific fixed point — then that vector is called a Localized Vector.

💡 উদাহরণ 💡 Example

অবস্থান ভেক্টর সবসময় মূলবিন্দু (O) থেকে শুরু হয়। লন রোলারকে টানার বল সবসময় হাতলের নির্দিষ্ট বিন্দু থেকে আঁকতে হয়। Position vector always starts from origin (O). The pulling force on a lawn roller must be drawn from the specific point on the handle.

🧠 মনে রাখো 🧠 Remember

সীমাবদ্ধ = বাঁধা = পাদবিন্দু নির্দিষ্ট। "Localized" মানে "স্থান-নির্দিষ্ট"।
🔗 স্বাধীন ভেক্টরের ঠিক বিপরীত ধারণা। Localized = fixed = tail is at a specific point.
🔗 Exact opposite concept of Free Vector.

▲ অবস্থান ভেক্টর — সবসময় O থেকে শুরু (সরানো যায় না) ▲ Position vector — always starts from O (cannot be moved)
🧭

খ. দিক ভিত্তিক ভেক্টর B. Direction Based Vectors

ভেক্টরগুলো কোন দিকে দেখাচ্ছে — একই দিকে, বিপরীত দিকে, নাকি অন্যভাবে? Which direction are the vectors pointing — same, opposite, or otherwise?

৩
সদৃশ ভেক্টর Like Vectors
Like / Parallel Vectors
▼
🔖 সংজ্ঞা 🔖 Definition

সমজাতীয় দুই বা ততোধিক ভেক্টর যদি একই দিকে ক্রিয়া করে, তবে তাদেরকে সদৃশ ভেক্টর বা সমান্তরাল ভেক্টর বলে। If two or more vectors of the same type act in the same direction, they are called Like Vectors or Parallel Vectors.

🧠 মনে রাখো 🧠 Remember

সদৃশ = "দেখতে একই রকম দিক" = একই দিকে তীর। মান ভিন্ন হতে পারে, কিন্তু দিক অবশ্যই একই। Like = same direction arrows. Magnitudes can differ, but direction must be the same.

▲ A⃗ ও B⃗ — ভিন্ন মান, কিন্তু একই দিক = সদৃশ ভেক্টর ▲ A⃗ & B⃗ — different magnitudes, same direction = Like Vectors
৪
বিসদৃশ ভেক্টর Unlike Vectors
Unlike Vectors
▼
🔖 সংজ্ঞা 🔖 Definition

সমজাতীয় দুটি ভেক্টর যদি বিপরীত দিকে ক্রিয়া করে, তবে তাদেরকে বিসদৃশ ভেক্টর বলে। If two vectors of the same type act in opposite directions, they are called Unlike Vectors.

🧠 মনে রাখো 🧠 Remember

বিসদৃশ = বিপরীত দিকে তীর। সদৃশের ঠিক উল্টো। তবে দুটোই সমান্তরাল (একই রেখা বরাবর বা সমান্তরাল রেখায়), শুধু দিক উল্টো। Unlike = arrows point in opposite directions. Exact opposite of Like Vectors. Both are still parallel, just opposite in direction.

▲ A⃗ ও B⃗ — বিপরীত দিক = বিসদৃশ ভেক্টর ▲ A⃗ & B⃗ — opposite directions = Unlike Vectors
৭
সমরেখ ভেক্টর Collinear Vectors
Collinear Vectors
▼
🔖 সংজ্ঞা 🔖 Definition

দুই বা ততোধিক ভেক্টর যদি একই সরলরেখা বরাবর বা পরস্পর সমান্তরালে ক্রিয়া করে, তবে তাদেরকে সমরেখ ভেক্টর বলে। If two or more vectors act along the same straight line or are parallel to each other, they are called Collinear Vectors.

🧠 মনে রাখো 🧠 Remember

"Co-linear" = "একই রেখায়"। সদৃশ ও বিসদৃশ ভেক্টর — দুটোই সমরেখ ভেক্টরের বিশেষ ক্ষেত্র। সমরেখ ভেক্টর একই দিকে বা বিপরীত দিকে — দুটোই হতে পারে। "Co-linear" = "on the same line". Both Like and Unlike vectors are special cases of Collinear Vectors. They can be in the same or opposite directions.

▲ A⃗, B⃗, C⃗ — একই রেখায় বা সমান্তরালে = সমরেখ ভেক্টর ▲ A⃗, B⃗, C⃗ — on same line or parallel = Collinear Vectors
৮
সমতলীয় ভেক্টর Coplanar Vectors
Coplanar Vectors
▼
🔖 সংজ্ঞা 🔖 Definition

দুই বা ততোধিক ভেক্টর যদি একই সমতলে অবস্থিত হয়, তবে তাদেরকে সমতলীয় ভেক্টর বলে। If two or more vectors lie on the same plane, they are called Coplanar Vectors.

🧠 মনে রাখো 🧠 Remember

"Co-planar" = "একই plane-এ"। যেকোনো দুটি ভেক্টর সবসময়ই সমতলীয় (কারণ দুটি সরলরেখা দিয়ে সবসময় একটি সমতল তৈরি করা যায়)। তিন বা ততোধিক ভেক্টরের ক্ষেত্রে প্রশ্ন আসে — এরা একই সমতলে আছে কিনা। "Co-planar" = "on the same plane". Any two vectors are always coplanar. The question arises for three or more vectors — whether they all lie on the same plane.

▲ A⃗, B⃗, C⃗ — একই সমতলে বিভিন্ন দিকে = সমতলীয় ভেক্টর ▲ A⃗, B⃗, C⃗ — different directions on same plane = Coplanar Vectors
📏

গ. মান ভিত্তিক ভেক্টর C. Magnitude Based Vectors

ভেক্টরের মান (সংখ্যাগত মান) কত — সমান, একক, শূন্য, নাকি বিপরীত সংখ্যা? What is the magnitude — equal, unit, zero, or reciprocal?

৫
সমান ভেক্টর Equal Vectors
Equal Vectors
▼
🔖 সংজ্ঞা 🔖 Definition

সমজাতীয় দুটি ভেক্টরের মান যদি সমান হয় আর তাদের দিক যদি একই দিকে হয়, তবে তাদেরকে সমান ভেক্টর বলে। If two vectors of the same type have equal magnitudes and the same direction, they are called Equal Vectors.

A⃗ = B⃗ ⟹ |A⃗| = |B⃗| এবং দিক একই
🧠 মনে রাখো 🧠 Remember

সমান ভেক্টর হতে হলে দুটি শর্ত পূরণ করতে হবে: ① মান সমান ② দিক একই।
পাদবিন্দু কোথায় তা গুরুত্বপূর্ণ নয়।
🔗 সদৃশ ভেক্টরের সাথে পার্থক্য: সদৃশে শুধু দিক একই হলেই হয়, মান সমান না হলেও চলে। For Equal Vectors, two conditions: ① Same magnitude ② Same direction.
Tail position doesn't matter.
🔗 Unlike Like Vectors, Equal Vectors require BOTH magnitude AND direction to match.

▲ A⃗ = B⃗ — সমান দৈর্ঘ্য, সমান দিক, ভিন্ন পাদবিন্দু ▲ A⃗ = B⃗ — same length, same direction, different tails
৬
ঋণাত্মক / বিপরীত ভেক্টর Negative Vector
Negative Vector
▼
🔖 সংজ্ঞা 🔖 Definition

নির্দিষ্ট দিক বরাবর কোনো ভেক্টরকে ধনাত্মক ধরলে, তার বিপরীত দিকে সমমানের সমজাতীয় ভেক্টরকে ঋণাত্মক ভেক্টর বা বিপরীত ভেক্টর বলে। If a vector in a certain direction is taken as positive, then a vector of the same magnitude in the opposite direction is called a Negative Vector.

PQ⃗ = A⃗ হলে, QP⃗ = −A⃗
🧠 মনে রাখো 🧠 Remember

ঋণাত্মক ভেক্টর = তীর ঘুরিয়ে দাও! মান একই, শুধু দিক উল্টো। P→Q ধনাত্মক হলে Q→P ঋণাত্মক। Negative vector = flip the arrow! Same magnitude, opposite direction. If P→Q is positive, Q→P is negative.

▲ A⃗ ও −A⃗ — সমান মান, বিপরীত দিক ▲ A⃗ and −A⃗ — same magnitude, opposite direction
৯
সঠিক ভেক্টর Proper Vector
Proper Vector
▼
🔖 সংজ্ঞা 🔖 Definition

যে সকল ভেক্টরের মান শূন্য নয় তাদেরকে সঠিক ভেক্টর বলে। Vectors whose magnitude is not zero are called Proper Vectors.

🧠 মনে রাখো 🧠 Remember

সহজ! মান ≠ 0 হলেই সঠিক ভেক্টর। আমরা সাধারণত যে সব ভেক্টর নিয়ে কাজ করি, প্রায় সবই সঠিক ভেক্টর। নাল ভেক্টর ছাড়া বাকি সব সঠিক ভেক্টর। Simple! If magnitude ≠ 0, it's a Proper Vector. Almost all vectors we deal with are Proper Vectors. Everything except the Null Vector is a Proper Vector.

১০
নাল / শূন্য ভেক্টর Null / Zero Vector
Null Vector / Zero Vector
▼
🔖 সংজ্ঞা 🔖 Definition

যে ভেক্টরের মান শূন্য তাকে নাল ভেক্টর বা শূন্য ভেক্টর বলে। A vector whose magnitude is zero is called a Null Vector or Zero Vector.

A⃗ + (−A⃗) = 0⃗
🧠 মনে রাখো 🧠 Remember

✦ পাদবিন্দু ও শীর্ষবিন্দু একই বিন্দুতে — অর্থাৎ ভেক্টরটি একটি "বিন্দু"।
✦ নাল ভেক্টরের কোনো সুনির্দিষ্ট দিক নেই।
✦ একটি ভেক্টরের সাথে তার ঋণাত্মক ভেক্টর যোগ করলে নাল ভেক্টর পাওয়া যায়।
✦ সংকেত: 0⃗ ✦ Tail and head at the same point — essentially a "dot".
✦ Null vector has no definite direction.
✦ Adding a vector to its negative gives the null vector.
✦ Symbol: 0⃗

▲ A⃗ + (−A⃗) = 0⃗ — ভেক্টর ও তার বিপরীত যোগ করলে শূন্য হয় ▲ A⃗ + (−A⃗) = 0⃗ — a vector plus its negative equals zero
১১
একক ভেক্টর Unit Vector
Unit Vector
▼
🔖 সংজ্ঞা 🔖 Definition

কোনো ভেক্টরের মান যদি একক (1) হয়, তাহলে তাকে একক ভেক্টর বলে। If the magnitude of a vector is unity (1), it is called a Unit Vector.

â = A⃗ / |A⃗|    (যেখানে |A⃗| ≠ 0)
💡 উদাহরণ 💡 Example

A⃗ = 5â হলে, â হলো A⃗ এর দিকে একক ভেক্টর। â এর মান 1, দিক A⃗ এর দিকে। If A⃗ = 5â, then â is the unit vector in the direction of A⃗. |â| = 1, direction is along A⃗.

🧠 মনে রাখো 🧠 Remember

✦ একক ভেক্টর = ভেক্টরকে নিজের মান দিয়ে ভাগ করলে পাওয়া যায়।
✦ সংকেত: অক্ষরের ওপরে হ্যাট (^) চিহ্ন: â, î, ĵ, k̂
✦ শুধু দিক নির্দেশ করে, মান সবসময় 1।
✦ যেকোনো ভেক্টর = মান × একক ভেক্টর → A⃗ = |A⃗| × â ✦ Unit vector = vector divided by its own magnitude.
✦ Symbol: hat (^) over the letter: â, î, ĵ, k̂
✦ Indicates only direction, magnitude is always 1.
✦ Any vector = magnitude × unit vector → A⃗ = |A⃗| × â

▲ A⃗ = 5â → â হলো একক ভেক্টর (মান = 1) ▲ A⃗ = 5â → â is the unit vector (magnitude = 1)
১৪
বিপ্রতীপ / ব্যতিহার ভেক্টর Reciprocal Vector
Reciprocal Vector
▼
🔖 সংজ্ঞা 🔖 Definition

সমজাতীয় দুটি সমান্তরাল ভেক্টরের একটির মান যদি অপরটির বিপরীত সংখ্যা (reciprocal) হয়, তবে তাদেরকে বিপ্রতীপ বা ব্যতিহার ভেক্টর বলে। If two parallel vectors of the same type have magnitudes that are reciprocals of each other, they are called Reciprocal Vectors.

A⃗ = 7î, B⃗ = (1/7)î → A⃗ ও B⃗ বিপ্রতীপ ভেক্টর
🧠 মনে রাখো 🧠 Remember

"Reciprocal" = "উল্টো সংখ্যা"। |A⃗| × |B⃗| = 1 হলেই বিপ্রতীপ। দুটো একই দিকে এবং সমান্তরাল। "Reciprocal" = "inverse number". If |A⃗| × |B⃗| = 1, they are reciprocal. They must be parallel and in the same direction.

📐

ঘ. অবস্থান ও সরণ ভিত্তিক ভেক্টর D. Position & Displacement Vectors

কোথায় আছো, কোথায় গেলে — এই তথ্য জানায় যে ভেক্টরগুলো। Vectors that tell you where you are and where you went.

১২
অবস্থান ভেক্টর Position Vector
Position Vector / Radius Vector
▼
🔖 সংজ্ঞা 🔖 Definition

প্রসঙ্গ কাঠামোর মূলবিন্দুর (O) সাপেক্ষে কোনো বিন্দুর অবস্থান যে ভেক্টর দিয়ে নির্দেশ করা হয়, তাকে ঐ বিন্দুর অবস্থান ভেক্টর বলে। The vector that indicates the position of a point with respect to the origin (O) of the reference frame is called the Position Vector of that point.

OP⃗ = r⃗ (ব্যাসার্ধ ভেক্টর / radius vector)
🧠 মনে রাখো 🧠 Remember

✦ সবসময় O থেকে শুরু — তাই এটি একটি সীমাবদ্ধ ভেক্টরও বটে।
✦ সংকেত: r⃗ (radius vector ও বলা হয়)।
✦ 2D তে: r⃗ = xî + yĵ
✦ 3D তে: r⃗ = xî + yĵ + zk̂ ✦ Always starts from O — hence it's also a Localized Vector.
✦ Symbol: r⃗ (also called radius vector).
✦ In 2D: r⃗ = xî + yĵ
✦ In 3D: r⃗ = xî + yĵ + zk̂

▲ O থেকে P পর্যন্ত = অবস্থান ভেক্টর r⃗ ▲ From O to P = position vector r⃗
১৩
সরণ ভেক্টর Displacement Vector
Displacement Vector
▼
🔖 সংজ্ঞা 🔖 Definition

কোনো বস্তুর অবস্থান ভেক্টরের পরিবর্তনকে সরণ ভেক্টর বলে। শেষ অবস্থান ভেক্টর থেকে আদি অবস্থান ভেক্টর বিয়োগ করলে সরণ ভেক্টর পাওয়া যায়। The change in position vector of an object is called the Displacement Vector. It equals the final position vector minus the initial position vector.

Δr⃗ = r⃗f − r⃗i
🧠 মনে রাখো 🧠 Remember

✦ সরণ = শেষ − আদি (final − initial)।
✦ এটি পথের দৈর্ঘ্য নয়, বরং আদি থেকে শেষ বিন্দু পর্যন্ত সোজা দূরত্ব ও দিক।
✦ সরণ ভেক্টর দিয়ে ত্রিভুজ তৈরি হয়: r⃗i, r⃗f, এবং Δr⃗ ✦ Displacement = final − initial.
✦ Not path length — it's the straight-line distance and direction from start to end.
✦ Forms a triangle: r⃗i, r⃗f, and Δr⃗

▲ Δr⃗ = r⃗f − r⃗i — অবস্থান পরিবর্তন = সরণ ▲ Δr⃗ = r⃗f − r⃗i — change in position = displacement
⚡

ঙ. বিশেষ ভেক্টর E. Special Vectors

ঘূর্ণন ও দিকের উপর ভিত্তি করে বিশেষ দুটি ভেক্টর Special vectors based on rotation and direction

১৫
অক্ষীয় ভেক্টর Axial Vector
Axial Vector (Pseudo Vector)
▼
🔖 সংজ্ঞা 🔖 Definition

যে ভেক্টর কোনো ঘূর্ণন অক্ষ বরাবর ক্রিয়া করে এবং যার দিক ডান-হাত নিয়মে (right-hand rule) নির্ধারিত হয়, তাকে অক্ষীয় ভেক্টর বলে। একে Pseudo Vector-ও বলা হয়। A vector that acts along the axis of rotation and whose direction is determined by the right-hand rule is called an Axial Vector. Also known as a Pseudo Vector.

💡 উদাহরণ 💡 Example

কৌণিক বেগ (ω⃗), কৌণিক ত্বরণ (α⃗), টর্ক (τ⃗), কৌণিক ভরবেগ (L⃗) — এগুলো সব অক্ষীয় ভেক্টর। Angular velocity (ω⃗), angular acceleration (α⃗), torque (τ⃗), angular momentum (L⃗) — all are axial vectors.

🧠 মনে রাখো 🧠 Remember

✦ ঘূর্ণন সংক্রান্ত রাশি হলেই সাধারণত অক্ষীয় ভেক্টর।
✦ ডান হাতের আঙুলগুলো ঘূর্ণনের দিকে বাঁকালে বৃদ্ধাঙুলি যে দিকে দেখায় — সেটাই ভেক্টরের দিক।
✦ দুটি ভেক্টরের ক্রস গুণফল থেকে অক্ষীয় ভেক্টর পাওয়া যায়। ✦ If it involves rotation, it's usually an axial vector.
✦ Curl fingers of right hand in rotation direction — thumb points in vector's direction.
✦ Cross product of two vectors gives an axial vector.

▲ ঘূর্ণন অক্ষ বরাবর ভেক্টর — ডান-হাত নিয়ম ▲ Vector along rotation axis — right-hand rule
১৬
মেরু / পোলার ভেক্টর Polar Vector
Polar Vector (True Vector)
▼
🔖 সংজ্ঞা 🔖 Definition

যে ভেক্টরের একটি সুনির্দিষ্ট প্রারম্ভিক বা প্রয়োগ বিন্দু থাকে এবং যা সরলরৈখিক প্রভাব নির্দেশ করে, তাকে মেরু ভেক্টর বা পোলার ভেক্টর বলে। একে True Vector-ও বলা হয়। A vector that has a definite starting/application point and represents a linear effect is called a Polar Vector. Also known as a True Vector.

💡 উদাহরণ 💡 Example

সরণ (r⃗), বেগ (v⃗), ত্বরণ (a⃗), বল (F⃗), রৈখিক ভরবেগ (p⃗) — এগুলো সব পোলার ভেক্টর। Displacement (r⃗), velocity (v⃗), acceleration (a⃗), force (F⃗), linear momentum (p⃗) — all are polar vectors.

🧠 মনে রাখো 🧠 Remember

✦ সরলরৈখিক গতি সংক্রান্ত ভেক্টর = পোলার ভেক্টর।
✦ ঘূর্ণন সংক্রান্ত ভেক্টর = অক্ষীয় ভেক্টর।
✦ পোলার ভেক্টর = "আসল" ভেক্টর, অক্ষীয় ভেক্টর = "ছদ্ম" ভেক্টর। ✦ Linear motion vectors = Polar Vectors.
✦ Rotational vectors = Axial Vectors.
✦ Polar = "true" vector, Axial = "pseudo" vector.

▲ বল, বেগ, সরণ — সরলরৈখিক ভেক্টর = পোলার ভেক্টর ▲ Force, velocity, displacement — linear vectors = Polar Vectors
💡

মনে রাখার কৌশল Memory Tips

🔗 জোড়ায় জোড়ায় মনে রাখো 🔗 Remember in Pairs

স্বাধীন ↔ সীমাবদ্ধ (পাদবিন্দু ইচ্ছেমতো ↔ নির্দিষ্ট)
সদৃশ ↔ বিসদৃশ (একই দিক ↔ বিপরীত দিক)
সমান ↔ ঋণাত্মক (সমান মান+দিক ↔ সমান মান+উল্টো দিক)
সঠিক ↔ নাল (মান ≠ 0 ↔ মান = 0)
অক্ষীয় ↔ পোলার (ঘূর্ণন ↔ সরলরৈখিক) Free ↔ Localized (tail anywhere ↔ fixed tail)
Like ↔ Unlike (same direction ↔ opposite direction)
Equal ↔ Negative (same mag+dir ↔ same mag+opposite dir)
Proper ↔ Null (mag ≠ 0 ↔ mag = 0)
Axial ↔ Polar (rotational ↔ linear)

🎯 সমান ভেক্টরের ২টি শর্ত 🎯 2 Conditions for Equal Vectors

"ম-দি" মনে রাখো:
✦ মান সমান
✦ দিক একই
দুটোই থাকতে হবে! শুধু একটি হলে সমান ভেক্টর নয়। "M-D" rule:
✦ Magnitude equal
✦ Direction same
Both must be satisfied!

🧮 একক ভেক্টরের সূত্র 🧮 Unit Vector Formula

"ভেক্টর ÷ মান = হ্যাট"
â = A⃗ / |A⃗|
অর্থাৎ A⃗ = |A⃗| × â → যেকোনো ভেক্টর = মান × একক ভেক্টর "Vector ÷ Magnitude = Hat"
â = A⃗ / |A⃗|
So A⃗ = |A⃗| × â → Any vector = magnitude × unit vector
