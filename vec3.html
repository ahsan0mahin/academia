Chapter 2.4 — Few Vectors

🎯 ভেক্টরের শ্রেণিবিভাগ

🎯 Classification of Vectors

পদার্থবিজ্ঞানে আমরা বিভিন্ন ধরনের ভেক্টর ব্যবহার করি। এই নোটসে আমরা ১৬ ধরনের ভেক্টর সম্পর্কে জানবো — প্রতিটির সংজ্ঞা, উদাহরণ, চিত্র ও মনে রাখার কৌশল সহ।

In physics, we use various types of vectors. In these notes, we'll learn about 16 types of vectors — with definitions, examples, diagrams, and memory tips.

📍 ক্যাটাগরি ১: পাদবিন্দুর ভিত্তিতে ভেক্টর Category 1: Based on Starting Point
১
স্বাধীন ভেক্টর
Free Vector
Free Vector
▼
সংজ্ঞা
Definition

কোনো ভেক্টর রাশির পাদবিন্দু (starting point) কোথায় হবে তা যদি ইচ্ছেমতো পছন্দ করা যায়, তবে সেই ভেক্টরকে স্বাধীন ভেক্টর বলে।

If the starting point (tail) of a vector can be chosen freely at any position, then that vector is called a Free Vector.

🔍 উদাহরণ
🔍 Example

5 N মানের পূর্বমুখী একটি বল — এটি একটি স্বাধীন ভেক্টর। কারণ এটিকে যেকোনো জায়গা থেকে আঁকলেও মান ও দিক একই থাকে।

A force of 5 N directed eastward — this is a free vector. No matter where you draw it from, its magnitude and direction remain the same.

দুটি ভেক্টর — ভিন্ন জায়গায় পাদবিন্দু, কিন্তু একই মান ও দিক → দুটোই সমান ✓
Two vectors — different starting points, same magnitude & direction → both are equal ✓
🔑 মূল কথা
🔑 Key Point

স্বাধীন ভেক্টর কোনো নির্দিষ্ট বিন্দুতে আবদ্ধ নয়। শুধু মান ও দিক গুরুত্বপূর্ণ, অবস্থান নয়।

A free vector is not tied to any specific point. Only magnitude and direction matter, not position.

🧠 মনে রাখার কৌশল
🧠 Memory Tip

"স্বাধীন" মানে "Free" — যেমন স্বাধীন পাখি যেখানে খুশি বসতে পারে, স্বাধীন ভেক্টরও যেখানে খুশি শুরু হতে পারে!

"Free" — like a free bird that can sit anywhere, a free vector can start from anywhere!

২
সীমাবদ্ধ ভেক্টর
Localized Vector
Localized Vector
▼
সংজ্ঞা
Definition

কোনো ভেক্টরের পাদবিন্দু যদি ইচ্ছেমতো পছন্দ করতে দেওয়া না হয় অর্থাৎ কোনো নির্দিষ্ট বিন্দুকে যদি পাদবিন্দু হিসেবে ঠিক করে রাখা হয়, তাহলে সেই ভেক্টরকে সীমাবদ্ধ ভেক্টর বলে।

If the starting point of a vector cannot be chosen freely, i.e., it must start from a specific fixed point, then it is called a Localized Vector.

🔍 উদাহরণ
🔍 Example

• অবস্থান ভেক্টর — সবসময় মূলবিন্দু (O) থেকে আঁকতে হয়।
• লন রোলারে টানা বল — হাতলের নির্দিষ্ট বিন্দু থেকে আঁকতে হয়।

• Position vector — must always start from the origin (O).
• Force pulling a lawn roller — must be drawn from the specific point on the handle.

অবস্থান ভেক্টর — সবসময় O বিন্দু থেকে শুরু (পাদবিন্দু নির্দিষ্ট)
Position vector — always starts from origin O (fixed starting point)
🧠 মনে রাখার কৌশল
🧠 Memory Tip

"সীমাবদ্ধ" = "Localized" → একটি নির্দিষ্ট জায়গায় "লক" (Lock) করা আছে। স্বাধীন ভেক্টরের ঠিক উল্টো!

"Localized" → "Locked" to a specific location. Exact opposite of free vector!

🧭 ক্যাটাগরি ২: দিকের ভিত্তিতে ভেক্টর Category 2: Based on Direction
৩
সদৃশ ভেক্টর
Like Vectors
Like / Parallel Vectors
▼
সংজ্ঞা
Definition

সমজাতীয় দুই বা ততোধিক ভেক্টর যদি একই দিকে ক্রিয়া করে তবে তাদেরকে সদৃশ বা সমান্তরাল ভেক্টর বলে।

When two or more vectors of the same type act in the same direction, they are called Like or Parallel Vectors.

A⃗ ও B⃗ — একই দিকে, তাই সদৃশ ভেক্টর (মান ভিন্ন হতে পারে)
A⃗ & B⃗ — same direction, so Like Vectors (magnitudes may differ)
🔑 মূল কথা
🔑 Key Point

সদৃশ ভেক্টরের মান ভিন্ন হতে পারে, কিন্তু দিক অবশ্যই একই।

Like vectors may have different magnitudes, but direction must be the same.

৪
বিসদৃশ ভেক্টর
Unlike Vectors
Unlike / Anti-parallel Vectors
▼
সংজ্ঞা
Definition

সমজাতীয় দুটি ভেক্টর যদি বিপরীত দিকে ক্রিয়া করে তবে তাদেরকে বিসদৃশ ভেক্টর বলে।

When two vectors of the same type act in opposite directions, they are called Unlike Vectors.

A⃗ ও B⃗ — বিপরীত দিকে, তাই বিসদৃশ ভেক্টর
A⃗ & B⃗ — opposite directions, so Unlike Vectors
🧠 মনে রাখার কৌশল
🧠 Memory Tip

সদৃশ = একই দিক (Like = Same) ↗↗
বিসদৃশ = উল্টো দিক (Unlike = Opposite) ↗↙

Like = Same direction ↗↗
Unlike = Opposite direction ↗↙

৫
ঋণাত্মক / বিপরীত ভেক্টর
Negative Vector
Negative Vector
▼
সংজ্ঞা
Definition

নির্দিষ্ট দিক বরাবর কোনো ভেক্টরকে ধনাত্মক ধরলে তার বিপরীত দিকে সমমানের সমজাতীয় ভেক্টরকে ঋণাত্মক ভেক্টর বা বিপরীত ভেক্টর বলে।

If a vector in a certain direction is considered positive, then a vector of the same magnitude in the opposite direction is called a Negative Vector.

P থেকে Q পর্যন্ত: PQ⃗ = A⃗   →   Q থেকে P পর্যন্ত: QP⃗ = −A⃗ From P to Q: PQ⃗ = A⃗   →   From Q to P: QP⃗ = −A⃗
A⃗ ও −A⃗ — একই মান, বিপরীত দিক
A⃗ & −A⃗ — same magnitude, opposite direction
🔑 মূল কথা
🔑 Key Point

ঋণাত্মক ভেক্টর মানে মান বদলায় না, শুধু দিক উল্টে যায় (180° ঘোরে)।

Negative vector means magnitude doesn't change, only direction reverses (rotates 180°).

📏 ক্যাটাগরি ৩: মানের ভিত্তিতে ভেক্টর Category 3: Based on Magnitude
৬
সমান ভেক্টর
Equal Vectors
Equal Vectors
▼
সংজ্ঞা
Definition

সমজাতীয় দুটি ভেক্টরের মান যদি সমান হয় আর তাদের দিক যদি একই দিকে হয় তবে তাদেরকে সমান ভেক্টর বলে। A⃗ = B⃗

If two vectors of the same type have equal magnitude and the same direction, they are called Equal Vectors. A⃗ = B⃗

A⃗ ও B⃗ — সমান দৈর্ঘ্য, একই দিক → A⃗ = B⃗ (পাদবিন্দু যেখানেই থাকুক)
A⃗ & B⃗ — equal length, same direction → A⃗ = B⃗ (regardless of starting point)
🔑 মূল কথা
🔑 Key Point

সমান ভেক্টরের জন্য দুটি শর্ত পূরণ হতে হবে:
১. মান সমান ✓
২. দিক একই ✓
পাদবিন্দুর অবস্থান ✗ (কোনো ব্যাপার না)

For equal vectors, two conditions must be met:
1. Equal magnitude ✓
2. Same direction ✓
Position of tail ✗ (doesn't matter)

🧠 তুলনা করো
🧠 Compare

সদৃশ → একই দিক (মান ভিন্ন হতে পারে)
সমান → একই দিক + একই মান

Like → same direction (magnitudes may differ)
Equal → same direction + same magnitude

৭
একক ভেক্টর
Unit Vector
Unit Vector
▼
সংজ্ঞা
Definition

কোনো ভেক্টরের মান যদি একক (1) হয় তাহলে তাকে একক ভেক্টর বলে। কোনো ভেক্টরকে তার মান দিয়ে ভাগ করলে সেই ভেক্টরের দিকে একটি একক ভেক্টর পাওয়া যায়।

A vector whose magnitude is unity (1) is called a Unit Vector. Dividing any vector by its magnitude gives a unit vector in that direction.

â = A⃗ / |A⃗| = A⃗ / A     ∴ A⃗ = A·â
A⃗ = 5â → বড় ভেক্টর A⃗ কে মান দিয়ে ভাগ করলে একক ভেক্টর â পাওয়া যায়
A⃗ = 5â → Dividing A⃗ by its magnitude gives unit vector â
🔑 মূল কথা
🔑 Key Point

• একক ভেক্টরের সংকেত: অক্ষরের ওপরে হ্যাট (^) চিহ্ন, যেমন â, î, ĵ, k̂
• একক ভেক্টর শুধু দিক নির্দেশ করে, মান সবসময় 1।

• Unit vector notation: hat (^) over the letter, like â, î, ĵ, k̂
• Unit vector indicates only direction, magnitude is always 1.

🧠 মনে রাখার কৌশল
🧠 Memory Tip

"একক" = "এক" → মান সবসময় এক (1)। ভেক্টরের "দিক-নির্দেশক কম্পাস"।

"Unit" = magnitude is always one (1). It's the "directional compass" of a vector.

৮
বিপ্রতীপ / ব্যতিহার ভেক্টর
Reciprocal Vector
Reciprocal Vector
▼
সংজ্ঞা
Definition

সমজাতীয় দুটি সমান্তরাল ভেক্টরের একটির মান যদি অপরটির বিপরীত সংখ্যা (reciprocal) হয়, তবে তাদেরকে বিপ্রতীপ বা ব্যতিহার ভেক্টর বলে।

If two parallel vectors of the same type have magnitudes that are reciprocals of each other, they are called Reciprocal Vectors.

যদি A⃗ = 7î হয়, তবে B⃗ = (1/7)î → A⃗ ও B⃗ বিপ্রতীপ ভেক্টর If A⃗ = 7î, then B⃗ = (1/7)î → A⃗ & B⃗ are reciprocal vectors
A⃗ (বড়) ও B⃗ (ছোট) — একই দিক, কিন্তু মান পরস্পরের উল্টো
A⃗ (long) & B⃗ (short) — same direction, magnitudes are reciprocals
🧠 মনে রাখার কৌশল
🧠 Memory Tip

"Reciprocal" = উল্টো ভগ্নাংশ। 7 এর reciprocal = 1/7। দিক একই থাকে, শুধু মান উল্টে যায়!

"Reciprocal" = flip the fraction. Reciprocal of 7 = 1/7. Direction stays same, only magnitude flips!

⭕ ক্যাটাগরি ৪: বিশেষ মানের ভেক্টর Category 4: Special Value Vectors
৯
সঠিক ভেক্টর
Proper Vector
Proper Vector
▼
সংজ্ঞা
Definition

যে সকল ভেক্টরের মান শূন্য নয় (≠ 0) তাদেরকে সঠিক ভেক্টর বলে।

Vectors whose magnitude is not zero (≠ 0) are called Proper Vectors.

🔑 মূল কথা
🔑 Key Point

নাল ভেক্টর ছাড়া সব ভেক্টরই সঠিক ভেক্টর। এটি সবচেয়ে সহজ সংজ্ঞা! মান > 0 হলেই সঠিক ভেক্টর।

All vectors except the null vector are proper vectors. Simplest definition! If magnitude > 0, it's a proper vector.

১০
নাল / শূন্য ভেক্টর
Null / Zero Vector
Null Vector / Zero Vector
▼
সংজ্ঞা
Definition

যে ভেক্টরের মান শূন্য (0) তাকে নাল ভেক্টর বা শূন্য ভেক্টর বলে। একটি ভেক্টরের সাথে তার বিপরীত ভেক্টর যোগ করে বা দুটি সমান ভেক্টর বিয়োগ করে নাল ভেক্টর পাওয়া যায়।

A vector whose magnitude is zero (0) is called a Null Vector or Zero Vector. It is obtained by adding a vector to its negative, or subtracting two equal vectors.

A⃗ + (−A⃗) = 0⃗     or     A⃗ − A⃗ = 0⃗
A⃗ + (−A⃗) = 0⃗ → পাদবিন্দু ও শীর্ষবিন্দু একই বিন্দুতে → মান = 0
A⃗ + (−A⃗) = 0⃗ → Tail and head at the same point → Magnitude = 0
🔑 মূল কথা
🔑 Key Point

• নাল ভেক্টরের কোনো সুনির্দিষ্ট দিক নেই
• পাদবিন্দু ও শীর্ষবিন্দু একই বিন্দুতে
• সংকেত: 0⃗

• Null vector has no definite direction
• Tail and head are at the same point
• Symbol: 0⃗

🧠 মনে রাখার কৌশল
🧠 Memory Tip

"Null" = শূন্য = Nothing। কিন্তু এটা ভেক্টর! শুধু "দৈর্ঘ্যহীন তীর" — একটা বিন্দু মাত্র।

"Null" = zero = nothing. But it's still a vector! Just a "zero-length arrow" — just a point.

📐 ক্যাটাগরি ৫: স্থানিক বিন্যাসের ভিত্তিতে ভেক্টর Category 5: Based on Spatial Arrangement
১১
সমরেখ ভেক্টর
Collinear Vectors
Collinear Vectors
▼
সংজ্ঞা
Definition

দুই বা ততোধিক ভেক্টর যদি একই সরলরেখা বরাবর বা পরস্পর সমান্তরালে ক্রিয়া করে তবে তাদেরকে সমরেখ ভেক্টর বলে।

Two or more vectors that act along the same line or are parallel to each other are called Collinear Vectors.

A⃗, B⃗, C⃗ — সমান্তরাল রেখায়, তাই সমরেখ ভেক্টর
A⃗, B⃗, C⃗ — on parallel lines, so Collinear Vectors
🔑 মূল কথা
🔑 Key Point

সমরেখ ভেক্টর একই দিকে বা বিপরীত দিকে হতে পারে — শর্ত হলো তারা একই রেখা বা সমান্তরাল রেখায় থাকবে।

Collinear vectors can be in same or opposite directions — condition is they lie on the same line or parallel lines.

১২
সমতলীয় ভেক্টর
Coplanar Vectors
Coplanar Vectors
▼
সংজ্ঞা
Definition

দুই বা ততোধিক ভেক্টর যদি একই সমতলে অবস্থিত হয় তবে তাদেরকে সমতলীয় ভেক্টর বলে।

Two or more vectors that lie in the same plane are called Coplanar Vectors.

A⃗, B⃗, C⃗ — বিভিন্ন দিকে, কিন্তু একই সমতলে → সমতলীয় ভেক্টর
A⃗, B⃗, C⃗ — different directions, but in the same plane → Coplanar Vectors
🧠 তুলনা করো
🧠 Compare

সমরেখ (Collinear) → একই রেখায় বা সমান্তরালে (1D চিন্তা)
সমতলীয় (Coplanar) → একই সমতলে (2D চিন্তা) — দিক যেকোনো হতে পারে

Collinear → on same line or parallel (think 1D)
Coplanar → on same plane (think 2D) — any direction allowed

Position Vector / Radius Vector
▼
সংজ্ঞা
Definition

প্রসঙ্গ কাঠামোর মূলবিন্দুর সাপেক্ষে কোনো বিন্দুর অবস্থান যে ভেক্টর দিয়ে নির্দেশ করা হয় তাকে ঐ বিন্দুর অবস্থান ভেক্টর বলে। একে ব্যাসার্ধ ভেক্টর (radius vector) ও বলা হয়।

The vector that indicates the position of a point relative to the origin of the reference frame is called the Position Vector of that point. Also called Radius Vector.

OP⃗ = r⃗
O (মূলবিন্দু) থেকে P বিন্দু পর্যন্ত → অবস্থান ভেক্টর r⃗
From O (origin) to point P → Position Vector r⃗
🔑 মূল কথা
🔑 Key Point

• অবস্থান ভেক্টর একটি সীমাবদ্ধ ভেক্টর (সবসময় O থেকে শুরু)
• সংকেত: r⃗
• এটি বস্তুর অবস্থান জানায়, গতি নয়

• Position vector is a localized vector (always starts from O)
• Symbol: r⃗
• It tells position, not motion

সরণ ভেক্টর
Displacement Vector
Displacement Vector
▼
সংজ্ঞা
Definition

কোনো বস্তুর অবস্থান ভেক্টরের পরিবর্তনকে সরণ ভেক্টর বলে। শেষ অবস্থান ভেক্টর থেকে আদি অবস্থান ভেক্টর বিয়োগ করলে সরণ ভেক্টর পাওয়া যায়।

The change in position vector of an object is called the Displacement Vector. It is the final position vector minus the initial position vector.

Δr⃗ = r⃗f − r⃗i
r⃗ᵢ (আদি) থেকে r⃗f (শেষ) → সরণ = Δr⃗ = r⃗f − r⃗ᵢ
r⃗ᵢ (initial) to r⃗f (final) → Displacement = Δr⃗ = r⃗f − r⃗ᵢ
🧠 মনে রাখার কৌশল
🧠 Memory Tip

অবস্থান ভেক্টর = "তুমি কোথায় আছো?" (O থেকে)
সরণ ভেক্টর = "তুমি কতটুকু সরেছো?" (আদি → শেষ)

Position Vector = "Where are you?" (from O)
Displacement Vector = "How far have you moved?" (initial → final)

অক্ষীয় ভেক্টর
Axial Vector
Axial Vector / Pseudo Vector
▼
সংজ্ঞা
Definition

যে ভেক্টর কোনো ঘূর্ণন অক্ষ বরাবর ক্রিয়া করে এবং যার দিক ডান হাতের নিয়ম (right-hand rule) দিয়ে নির্ধারিত হয়, তাকে অক্ষীয় ভেক্টর বলে। একে ছদ্ম ভেক্টর (pseudo vector)-ও বলা হয়।

A vector that acts along the axis of rotation and whose direction is determined by the right-hand rule is called an Axial Vector. Also called a pseudo vector.

🔍 উদাহরণ
🔍 Example

• টর্ক (τ⃗) — ঘূর্ণন অক্ষ বরাবর
• কৌণিক বেগ (ω⃗) — ঘূর্ণন অক্ষ বরাবর
• কৌণিক ভরবেগ (L⃗)

• Torque (τ⃗) — along rotation axis
• Angular velocity (ω⃗) — along rotation axis
• Angular momentum (L⃗)

ডান হাতের নিয়ম: আঙুল ঘূর্ণনের দিকে কুঁড়লে, বুড়ো আঙুল ভেক্টরের দিক দেখায়
Right-hand rule: curl fingers in rotation direction, thumb points in vector direction
🧠 মনে রাখার কৌশল
🧠 Memory Tip

"Axial" = "Axis" → যেটা অক্ষ (axis) বরাবর থাকে। ঘূর্ণনের সাথে সম্পর্কিত রাশি হলেই অক্ষীয় ভেক্টর!

"Axial" = "Axis" → lies along the axis. If related to rotation, it's axial!

১৬
পোলার ভেক্টর
Polar Vector
Polar Vector / True Vector
▼
সংজ্ঞা
Definition

যে ভেক্টরের একটি নির্দিষ্ট শুরু বিন্দু (বা ক্রিয়া বিন্দু) আছে এবং যা সরলরেখা বরাবর ক্রিয়া করে (ঘূর্ণন সম্পর্কিত নয়), তাকে পোলার ভেক্টর বলে। একে প্রকৃত ভেক্টর (true vector)-ও বলা হয়।

A vector that has a definite starting point and acts along a straight line (not related to rotation) is called a Polar Vector. Also called a true vector.

🔍 উদাহরণ
🔍 Example

• বল (F⃗)
• সরণ (Δr⃗)
• বেগ (v⃗)
• ভরবেগ (p⃗)
• ত্বরণ (a⃗)

• Force (F⃗)
• Displacement (Δr⃗)
• Velocity (v⃗)
• Momentum (p⃗)
• Acceleration (a⃗)

পোলার ভেক্টর — সরলরেখা বরাবর ক্রিয়া করে (বল, বেগ ইত্যাদি)
Polar Vector — acts along a straight line (force, velocity, etc.)
🧠 তুলনা: অক্ষীয় vs পোলার
🧠 Compare: Axial vs Polar

পোলার → সরলরেখা বরাবর → বল, বেগ, সরণ (সরল গতি)
অক্ষীয় → ঘূর্ণন অক্ষ বরাবর → টর্ক, কৌণিক বেগ (ঘূর্ণন গতি)

Polar → along a line → force, velocity, displacement (linear motion)
Axial → along rotation axis → torque, angular velocity (rotational motion)
